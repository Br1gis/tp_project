## 🎮 Доступные команды / Available Commands

| Команда | Описание и Шаблон |
| :--- | :--- |
| 🎲 `/dice` | Игра в кубик. Шаблон: `/dice <чёт/нечёт> <ставка>` |
| 🪙 `/coinflip` | Игра в монетку. Шаблон: `/coinflip <орёл/решка>` |
| 📝 `/reg` | Регистрация в системе |
| 👤 `/profile` | Посмотреть свой профиль |
| 💋 `/kiss` | Поцеловать кого-либо. Шаблон: `/kiss <@юзернейм>` |
| ⚔️ `/duel` | Дуэль на деньги. Шаблон: `/duel <@оппонент> <ставка>` |
| 💍 `/marry` | Вступить в брак. Шаблон: `/marry <@пользователь>` |
| 💔 `/divorce` | Расторгнуть существующий брак |
| 🤝 `/handshake` | Пожать руку. Шаблон: `/handshake <пользователь>` |
| 🏆 `/top` | Посмотреть Топ-10 пользователей |
| 🏪 `/shop` | Открыть магазинчик |
